# Функциональные требования MVP

**Версия:** 0.1 · **Дата:** 13 октября 2026  
**Статус:** НА СОГЛАСОВАНИИ  
**Решения и допущения:** [D-01…D-09](README.md).

## 1. Задача и аудитория

Пользователь формулирует собственные мысли на английском, сравнивает исходную и улучшенную речь, понимает результат через перевод и закрепляет новые выражения в карточках. MVP — устанавливаемое Android-приложение, Android 13+, не веб-страница в оболочке.

Предназначено для публичной аудитории. Каждый пользователь оплачивает запросы собственным ключом OpenRouter. Что означает «зарегистрированный», решается в D-01; отдельная регистрация приложения здесь не считается утверждённой.

Альтернатива текущему сценарию — раздельно использовать диктофон, ИИ-чат и карточки. MVP объединяет их вокруг одного текста и сохраняет связь слова с исходным контекстом. Сравнение с конкурентами и рыночные обещания не являются предметом этого ТЗ.

## 2. Объём и исключения

Включены запись/журнал, А, редактируемый источник, Б, перевод Б, контекстный перевод, словарь, карточки SM-2, настройки и локальная SQLite.

Не включены iOS, веб-версия MVP, свой сервер, свой биллинг, облачная синхронизация, социальные функции, чат-собеседник, оценка произношения, автоматическое определение CEFR, работа моделей офлайн, запись в фоне и диаризация. Перечень D-08 согласуется отдельно.

## 3. Настройки

| ID | Требование | Проверяемое поведение |
|---|---|---|
| SET-01 | Подключение OpenRouter | Ввод, замена и удаление собственного ключа. Сохранённое значение не раскрывается повторно. Ключ не включён в SQLite и обычные настройки. |
| SET-02 | Выбор STT | Отдельный ограниченный список моделей А; видны название, назначение, доступность и ID. |
| SET-03 | Выбор текстовой модели | Отдельный ограниченный список моделей Б. Эта же модель используется для переводов; третьего селектора нет. |
| SET-04 | Уровни | Настраиваемые текущий и целевой CEFR. Начальные B1/B2 — предложение; B2 и C1 доступны для B1. Правила D-04. |
| SET-05 | Родной язык | Русский по умолчанию. Изменяется независимо от интерфейса и обучения. Предложенный список — D-03. |
| SET-06 | Интерфейс и обучение | По D-03: EN/RU интерфейс, EN default; единственный язык обучения — EN, явно показан. |
| SET-07 | Тема | Следовать системной теме; макеты и реализация обеих системных схем. |
| SET-08 | Учебная сессия | Максимум 10 уникальных карточек на сессию; размер не настраивается в MVP по D-08. |
| SET-09 | Инструкция Б | По D-06: редактирование, сохранение, сброс после подтверждения. Исходная инструкция — согласованная инструкция прототипа с целевым уровнем из настройки. Изменённая инструкция применяется вместо исходной, без скрытого добавления исходного текста. |
| SET-10 | Параметры | Б: temperature 0.2, top_p 1, max_tokens 2048; seed не задан. Диапазоны 0…2, (0…1], 64…4096, seed 0…2147483647. А: temperature 0, диапазон 0…1, только если поддержка выбранной модели подтверждена. |
| SET-11 | Сохранение | Настройки переживают перезапуск. Изменение настроек влияет только на последующие запросы; начатая цепочка использует свой снимок. |
| SET-12 | Очистка | Удалить ключ отдельно от учебных данных. «Удалить все локальные данные» требует подтверждения, удаляет аудио, тексты, словарь, прогресс, настройки и ключ. |

При выборе другой модели несовместимый параметр не переносится молча: пользователь видит, что недоступно, и подтверждает новые defaults. При ошибке поддержки не подменять модель и не повторять запрос автоматически.

## 4. Аудио и журнал

| ID | Требование |
|---|---|
| AUD-01 | Перед первой записью объяснить назначение микрофона, запросить системное разрешение. Отказ не блокирует словарь/ранее сохранённые материалы. |
| AUD-02 | Запуск, остановка, отмена; таймер и явный индикатор записи. По D-09 — автоостановка через 120 секунд, размер до 10 MiB. |

| AUD-04 | При отмене, ошибке или нехватке места предыдущие данные остаются. Неполный временный файл не выдаётся за сохранённую запись. |
| AUD-05 | Прослушивание, перемотка и удаление выбранной записи. Список по убыванию даты, постраничная/виртуализированная загрузка. |
| AUD-06 | Хранилище по D-05; перед заполнением памяти предупредить. Никакого удаления старых записей автоматически. |
| AUD-07 | При уходе в фон/звонке остановить запись; пригодный фрагмент предложить сохранить после возврата, иначе удалить временный файл с сообщением. Фоновая запись не поддерживается. |
| AUD-08 | Удаление аудио предлагает явно: «Только аудио, оставить тексты» или «Запись и связанные тексты». Карточки словаря остаются в обоих случаях, ссылка на источник помечается удалённой. |

## 5. Распознавание и улучшение

| ID | Требование |
|---|---|
| TXT-01 | А — английская расшифровка выбранной записи. Стремиться сохранить ошибки, повторы и слова-паразиты; пунктуация допустима. Не применять скрытую «очистку» другой моделью. |
| TXT-02 | Оригинал А неизменяем; рядом отдельная редактируемая копия. Поддержать выделение, копирование, вставку, сохранение правки. |
| TXT-03 | Повтор А — платный запрос после предупреждения. Заменить А и редактируемый источник только после успешного ответа и подтверждения замены правок; связанные Б/переводы становятся устаревшими. Ошибка не удаляет предыдущее А. |
| TXT-04 | Б строится по редактируемому источнику и выбранному уровню, а не по повторному распознаванию аудио. Пустой источник блокирует Б. |
| TXT-05 | Сохранить факты, имена, числа, даты, отрицания, условия, причинность, временные отношения, намерение и степень уверенности. Не придумывать опыт или достижения для интервью. |
| TXT-06 | Стиль естественный и уместный, без механического усложнения и обязательных идиом. Отметка CEFR означает заданный уровень, не сертификацию качества результата. |
| TXT-07 | Для одной записи можно получить результаты разных уровней. По D-09 хранить последний Б каждого уровня со снимком источника, модели, параметров и инструкции. Перезапись только после успешного результата. |
| TXT-08 | Изменение источника, уровня, модели Б или инструкции/параметров помечает не соответствующие текущим настройкам результаты устаревшими. Их можно открыть; обновление только явным действием. |
| TXT-09 | Обрезанный по токенам ответ виден как неполный, не считается успешным Б и не запускает перевод автоматически. |
| TXT-10 | Открывать и удалять текстовый материал независимо от наличия аудио. Удаление материала удаляет его А, источник, Б и переводы после подтверждения, но оставляет аудио и сохранённые карточки. |
| TXT-11 | Прослушивать текст А/источник/Б системным TTS английского. Это озвучивание текста, не оригинальная запись. Нет голоса/движка — явное объяснение; установка голоса через настройки Android. |

При пользовательской инструкции Б предупреждать: изменение может ослабить сохранение смысла. Требование TXT-05 остаётся критерием продукта; произвольная инструкция не даёт технической гарантии его выполнения.

## 6. Перевод улучшенного текста

| ID | Требование |
|---|---|
| TR-01 | После успешного Б автоматически выполнить отдельный перевод **именно Б**, а не А, на родной язык из снимка настроек цепочки. |
| TR-02 | Б сохранить до перевода. Ошибка перевода не превращает успешный Б в потерянный результат. Блок показывает ошибку и кнопку повтора только перевода. |
| TR-03 | При каждом открытии результата и после нового Б перевод свёрнут. Заголовок: «Перевод · [язык]» и состояние. Разворачивание/сворачивание — локальное действие без API. |
| TR-04 | Перевод сохраняет смысл Б, не улучшает его заново и не добавляет объяснений. Он не участвует в оценке английского CEFR. |
| TR-05 | Перевод связан с ID/редакцией Б, целевым языком и фактически использованной моделью. Правка Б делает прежний перевод устаревшим. |
| TR-06 | Смена родного языка не меняет старые переводы и не запускает платные запросы. Старый язык явно виден; предложить явное создание перевода на текущий язык. |
| TR-07 | Если родной язык EN, сохранить локально Б как перевод без дополнительного запроса; блок по-прежнему свёрнут. |
| TR-08 | Для перевода используется отдельная штатная инструкция и выбранная модель Б. Редактирование инструкции улучшения не отключает TR-01. Defaults перевода: temperature 0.1, top_p 1, max_tokens 2048; неподдерживаемость обработать явно. |

Предложено позволить редактировать Б как отдельную локальную редакцию без изменения ответа модели; оригинал Б сохраняется для оценки. Такое редактирование включает TR-05.

## 7. Контекстный перевод и словарь

| ID | Требование |
|---|---|
| VOC-01 | Выделить английское слово/фразу в источнике или Б; показать контекстный перевод на родной язык. Отправить только выделение и достаточное предложение-контекст. |
| VOC-02 | Добавить карточку с выражением, переводом, примером и ссылкой на источник. До сохранения все поля, кроме ссылки, можно исправить. |
| VOC-03 | При ошибке перевода предложить ручной ввод; карточка не теряется. |
| VOC-04 | Добавить карточку вручную без обращения к ИИ. Английский текст и перевод обязательны. |
| VOC-05 | Список, поиск по слову/переводу, просмотр, редактирование и удаление карточки после подтверждения. |
| VOC-06 | Дубликат определяется по нормализованному английскому выражению и паре языков. Предупредить; позволить открыть существующую или сохранить отдельное значение с другим контекстом. Не удалять значения автоматически. |
| VOC-07 | Карточка хранит язык перевода на момент создания. Смена родного языка не переписывает словарь; обучение использует карточки текущей пары языков. Старые доступны через фильтр. |
| VOC-08 | Редактирование текста/перевода сохраняет прогресс SM-2; отдельная команда сброса прогресса требует подтверждения. |

## 8. Обучение SM-2

- LRN-01: сессия до 10 уникальных карточек текущей пары языков. Сначала просроченные по сроку, затем новые до заполнения; если меньше — не дополнять повторами или чужой парой языков.
- LRN-02: лицевая сторона — английское слово/выражение, перевод скрыт. «Показать ответ» раскрывает перевод и пример; оценки до раскрытия недоступны.
- LRN-03: оценки «Снова / Трудно / Хорошо / Легко», соответствие SM-2 q=0/3/4/5. Стандартные начальные EF=2.5, минимум EF=1.3; успешные интервалы 1 день, 6 дней, далее по формуле SM-2; q<3 сбрасывает успешную последовательность.
- LRN-04: каждая оценка атомарно сохраняет прогресс и событие повторения. Двойное нажатие не создаёт вторую оценку. После закрытия приложения завершённые оценки не теряются.
- LRN-05: после «Снова» допускается дополнительный показ той же карточки в конце текущей сессии; это учебное повторение, не дополнительная оценка расписания до нового явного ответа. В итогах считать уникальные карточки отдельно от показов.
- LRN-06: итог — число оценённых уникальных карточек и распределение оценок. Закрытие сессии до оценки не считается успешным повторением.
- LRN-07: обучение работает офлайн. Использовать готовую поддерживаемую реализацию SM-2 после проверки лицензии/совместимости; FSRS в MVP не включать.
- LRN-08: даты хранить с часовым поясом расчёта и UTC-моментом срока; изменение часового пояса не сбрасывает прогресс. Правила округления календарных дней зафиксировать в тестах до реализации планировщика.

## 9. Сеть, расходы и сохранность

- NET-01: перед первым обращением объяснить передачу аудио/текстов OpenRouter и исполнителю модели, платность и возможность сохранения у провайдера.
- NET-02: А и Б запускает пользователь. Б может запустить второй платный запрос для перевода; «улучшить аудио» без А — до трёх последовательных запросов. Количество запросов видно до запуска.
- NET-03: цепочка использует один снимок ключа/настроек. Замена или удаление ключа отменяет активную цепочку; поздний ответ не восстанавливает ключ и не перезаписывает новые данные.
- NET-04: одна активная цепочка ИИ на устройстве; без автоматических повторов и подмен моделей. Отмена и таймаут не гарантируют отмену списания.
- NET-05: по D-02 таймаут 60 секунд **на запрос**, включая отправку данных. Показывать текущий этап, отмену и ошибку; не обещать фиксированное время ответа.
- NET-06: различать нет сети, неверный ключ, недостаток средств, лимит, модель недоступна, несовместимые параметры, таймаут, неполный/некорректный ответ.
- NET-07: если приложение ушло в фон, прервать ожидание на стороне клиента; отметить незавершённый запрос, не продолжать цепочку автоматически. У провайдера запрос мог завершиться и списать средства.
- NET-08: запись, журнал, редактирование, ручной словарь и обучение работают офлайн. ИИ и контекстный перевод требуют сети и ключа.
- NET-09: сохранять каждую успешную стадию транзакционно. После ошибки следующей стадии доступен предыдущий результат.
- NET-10: defaults ограничений — аудио 120 секунд/10 MiB, источник 10 000 символов, инструкция 20 000. Суммарный запрос должен помещаться в подтверждённый контекст выбранной модели. Отказ до отправки, без скрытой обрезки.
- NET-11: стоимость из ответа показывается только если получена; неизвестная стоимость не означает нулевую. Приложение не гарантирует денежный лимит: пользователь задаёт бюджет/лимит ключа у OpenRouter.

## 10. Критерии приёмки

Все обязательные сценарии должны пройти на Android 13 и Android 14; минимальный тестовый экран 360 dp, системные светлая/тёмная темы, увеличенный шрифт и отсутствие сети. Дополнительная актуальная версия Android — перед публичным выпуском.

|---|---|

| AC-02 | Нет ключа/сети → записать и вручную добавить карточку → данные сохраняются; платные операции недоступны с объяснением. |
| AC-03 | Есть две записи → создать/отменить третью → предыдущие две не изменились; завершённая третья добавилась отдельно. |
| AC-04 | Получено А → изменить копию → Б использует копию; оригинал А остался прежним. |
| AC-05 | Б успешно, перевод RU успешно → открыть/перезапустить/снова открыть → перевод сохранён и свёрнут; раскрытие не делает запрос. |
| AC-06 | Б успешно, перевод завершился ошибкой → повторить перевод → Б не генерируется повторно и не теряется. |
| AC-07 | Сохранён перевод RU → сменить родной на DE → старый помечен RU, автоматического запроса нет; новый Б переводится в DE. |
| AC-08 | Выбран родной EN → получить Б → дополнительный запрос перевода отсутствует. |
| AC-09 | Изменить источник/Б/настройки → открыть старые результаты → видны признаки устаревания и реальные снимки настроек. |
| AC-10 | Выделить выражение → перевести и сохранить/исправить → карточка содержит контекст и язык, доступна после перезапуска. |
| AC-11 | Есть карточки → офлайн оценить/двойным нажатием/перезапустить → одна оценка, корректный SM-2 и сохранённый прогресс. |
| AC-12 | Удалить аудио или текст → открыть словарь → карточки и прогресс остались, удалённый источник обозначен. |
| AC-13 | Неверный ключ/402/429/таймаут/недоступная модель → вызвать ИИ → понятная ошибка, старые данные на месте, нет скрытого повторного списания через автоповтор. |
| AC-14 | Обрезанный Б → открыть результат → «Неполный», перевод автоматически не запущен. |
| AC-15 | Прервать цепочку/сменить ключ/уйти в фон → вернуться → поздний ответ не заменяет актуальные данные и не продолжает операции. |
| AC-16 | Нет места или сбой SQLite → сохранить → нет ложного сообщения об успехе; пользователь видит проблему, старые данные читаются. |
| AC-17 | Удалить все локальные данные → перезапустить → ключ, записи, тексты, карточки и прогресс отсутствуют. |

### Качество моделей

Предлагается контрольный набор не менее 10 записей: 6 бытовых и 4 интервью, с ошибками/повторами/акцентом, плюс тексты разных разрешённых пар CEFR. Для каждой выпущенной модели проверять её назначение: STT — точность и отсутствие систематической «очистки»; текстовая — Б, перевод Б и контекстный перевод.

Базовые пороги: агрегированный WER А ≤15%; ноль существенных искажений смысла Б/перевода на контрольном наборе; ≥8 из 10 Б для каждого проверяемого уровня получают ≥7/8 по грамматике, естественности, уровню и регистру, без нулевой оценки. Предложены по образцу прототипа, не гарантируют качество на любой речи. Не прошедшие кандидаты не включаются в выпускной список; провал метрик обсуждается, а не скрывается.

Приёмка безопасности — отдельный обязательный раздел [SEC-TEST](security-requirements.md).
