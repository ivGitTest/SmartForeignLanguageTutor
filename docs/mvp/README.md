# MVP — пакет на согласование

**Версия пакета:** 0.2

**Дата:** 13 октября 2026  
**Статус:** НА СОГЛАСОВАНИИ. Реализация MVP не начата.  
**Подготовка:** Replit Agent. **Согласование:** владелец продукта.

Пользователь проверил прототип и сообщил: «в целом всё устраивает». Это разрешение готовить документацию MVP, не утверждение о прохождении всех формальных метрик качества.

## Документы

1. [Функциональные требования](functional-requirements.md) — возможности, правила данных, состояния и критерии приёмки.
2. [Требования к безопасности](security-requirements.md) — защита пользовательских ключей, приватность, расходы и проверки перед выпуском.
3. [Требования к дизайну экранов](screen-design-requirements.md) — навигация, состав экранов, состояния и требования к Figma.
4. [Архитектурная справка](architecture.md) — приложение без собственного сервера, компоненты, локальные данные и внешние API.

Основание: [общий черновик](../business-functional-requirements-draft.md) и [ТЗ прототипа](../prototype-technical-requirements.md). Прототип остаётся отдельным веб-инструментом; его сервер, ключ и ограничение одним владельцем не переносятся в мобильный MVP.

Обязательная [терминология](../terminology.md): режимы Материалы, Словарь и Обучение; А — транскрибация, как есть; Б — транскрибация с улучшением; Перевод — перевод Б на родной язык.

## Что прямо подтвердил пользователь

- Android-приложение для публичной аудитории; в MVP нет регистрации, авторизации и собственного аккаунта приложения. Защита входа — средствами ОС.
- Собственные пользовательские ключи и оплата; OpenRouter — единственный провайдер MVP.
- Два ограниченных списка моделей: для А и Б; доступные тарифы показываются с корректной единицей расчёта.
- Предпочтение MVP без собственного сервера.
- Настройка родного языка, русский по умолчанию, перевод после улучшения, свёрнутый по умолчанию.
- Функции с пометкой MVP из исходного черновика; SQLite и Figma.
- Неизменность существенного смысла.
- Старт в режиме Словарь; режимы Материалы и Обучение независимы. Их состояние и прогресс переживают переключение и перезапуск.
- Учебная сессия до 10 карточек; затем предложить продолжить следующей сессией или выйти. Новые слова не включать в уже начатую сессию.
- Только светлая тема MVP; системная и тёмная — развитие.
- Видимые редактируемые промпты, свёрнутые по умолчанию; резет настроек восстанавливает defaults и промпты вместо очистки данных.
- На материал — одно аудио, одна актуальная А, одна актуальная Б и связанный Перевод. После правки А новая Б заменяет старую; истории Б по уровням нет.
- Только аудио → А → Б → Перевод; нет операции «улучшить аудио» без А.
- В окне Б — контекстный перевод и добавление карточки; редактирование карточек только в режиме Словарь.
- Нет повторного предупреждения о платности перед А; для только что записанного аудио без связанных артефактов удаление сразу, без подтверждения.

Остальные уточнения пакета — предложения для согласования. Статус всего пакета остаётся черновым до решения владельца.

## Решения, которые нужно согласовать

| ID | Вопрос | Предлагаемое решение | Влияние |
|---|---|---|---|
| D-01 | Вход — решено пользователем | Никакой регистрации или авторизации приложения; защита средствами ОС. Ключ OpenRouter — только доступ к API. | Нет аккаунтов, экранов входа, токенов сессии и user ID. |
| D-02 | Таймаут | 60 секунд на каждый сетевой запрос вместо исходных 10; настройку произвольного таймаута отложить. | А запускается отдельно; Б и следующий за ней Перевод могут занять два отдельных таймаута. |
| D-03 | Языки | Интерфейс EN/RU, по умолчанию EN; родной RU/EN/DE/FR/ES, по умолчанию RU; обучение EN. | Список родных языков — предложение, не уже реализованная возможность. |
| D-04 | Уровни | Текущий A1–C2; целевой выше текущего. При текущем C2 улучшение до более высокого уровня недоступно. | Прототип проверял только B1→B2/C1; другие пары требуют проверки. |
| D-05 | Хранение | SQLite и аудио в приватном хранилище приложения; без облачной синхронизации и автоматических резервных копий. | Удаление приложения/данных может привести к потере материалов; общей папки в файловом менеджере нет. |
| D-06 | Промпты | Редакторы промптов Б, Перевода и контекстного перевода, свёрнутые по умолчанию. Промпт А — только при подтверждённой поддержке STT. | Некоторые STT endpoints игнорируют общий `prompt`; интерфейс не должен обещать его применение. |
| D-07 | Ограниченные списки | Три кандидата STT и три текстовых, перечисленные в архитектуре. Defaults — Whisper Large V3 и GPT-4.1 Mini. | Итоговый выпускной список содержит только модели, прошедшие реальную проверку; произвольного ввода ID нет. |
| D-08 | Граница MVP | Экспорт CSV/Anki, FSRS, выбор каталога и настраиваемый размер сессии отложить; только светлая тема по указанию пользователя. | Системная/тёмная тема — развитие. |
| D-09 | Обработка и история | 120 секунд / 10 MiB на запись; одна текущая цепочка артефактов на материал, без истории Б по уровням. | Уровень/правка А меняют вход Б, но не создают параллельную версию Б. |
| D-10 | Границы резета | Восстановить обычные настройки и все промпты; сохранить ключ, материалы, словарь и прогресс. Удаление ключа — отдельная команда. | Предложено явно отделить резет от разрушительной очистки; команду «удалить все данные» убрать из MVP. |

Прямые изменения пользователя включены без повторного выбора. Значения и технические предложения D-02…D-10 можно принять вместе с пакетом либо перечислить исключения. Поддержка редактируемого промпта А зависит от фактического STT endpoint; не добавлять неработающий редактор.

## Что означает согласование

1. Зафиксирован состав MVP, значения по умолчанию и исключения.
2. Согласованы решения D-01…D-10 либо их исправленные варианты.
3. Можно переходить к макетам Figma, но не считать их заранее утверждёнными.
4. Реализация — только после согласования требований и экранов.
