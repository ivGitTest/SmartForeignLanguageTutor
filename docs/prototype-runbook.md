# Прототип English Lab: запуск и проверка

Утверждённые требования: [ТЗ 0.3](prototype-technical-requirements.md).

## Среда

Веб-прототип для ПК и Firefox: `/language-prototype/`.
API: `/language-prototype/api/v1/`.
Общие маршруты встроенной аутентификации: `/api/login`, `/api/callback`,
`/api/logout`, `/api/auth/user`. Вход — через существующий аккаунт.

Сервисы запускаются управляемыми процессами:

- `artifacts/api-server: API Server`;
- `artifacts/language-prototype: web`.

Для проверки:

```sh
pnpm run typecheck
pnpm --filter @workspace/api-server test
pnpm --filter @workspace/api-server build
```

Нужен установленный `ffmpeg`/`ffprobe` для проверки фактического содержимого
аудио и длительности. В текущей среде они уже доступны.

## Обязательная настройка

1. `OPENROUTER_API_KEY` — секрет на сервере, добавляется только через защищённое
   хранилище проекта. Не вводить в интерфейс приложения, документацию или Git.
2. `PROTOTYPE_OWNER_USER_ID` — ID единственного разрешённого пользователя.
   Войдите в приложение: при ненастроенном владельце экран покажет **ваш**
   подтверждённый ID. Добавьте его в переменные окружения сервера.
   До этого платные операции заблокированы. Первый вошедший пользователь
   **не** назначается владельцем автоматически.
3. Для входа используется стандартная интеграция OIDC и таблицы
   `users`/`sessions` в существующей PostgreSQL. В базе нет аудио,
   транскриптов, результатов улучшения или пользовательских инструкций.

После изменения серверных настроек перезапустите процесс API.

## Данные и стоимость

Последний законченный фрагмент, тексты и настройки находятся в IndexedDB
браузера. Они не синхронизируются между устройствами. Очистка данных сайта
удаляет локальные записи. Выход очищает чувствительные данные; настройки
сохраняются отдельно для этого пользователя.

Начало новой записи не должно удалять старую. Замена выполняется только после
успешного завершения и сохранения нового непустого фрагмента.

Распознавание и улучшение выполняются только после явного нажатия пользователя.
Отмена ожидания не гарантирует отмену списания у провайдера. Повторов по сети
автоматически нет. Стоимость показывается только если провайдер её вернул;
отсутствующее значение не означает бесплатный запрос.

Временные серверные файлы аудио удаляются в `finally`. Оставшиеся после аварии
каталоги старше 15 минут убираются при запуске и периодически.

## Приёмка

Технические проверки не подтверждают качество ИИ. Для приёмки нужны реальные
английские записи в Firefox и оплаченный доступ к моделям: десять исходных
фрагментов (шесть бытовых и четыре ответа на собеседовании), каждый улучшить
в B2 и C1. Проверить точность A, неизменность смысла, естественность,
грамматику и соответствие уровню по критериям ТЗ.

Отдельно проверить: отказ в разрешении микрофона, отмену записи/запроса,
перезагрузку страницы, сохранение изменённой инструкции и параметров,
устаревшие результаты после правки A, сохранение старых данных при ошибке
провайдера, превышение лимитов и доступ не-владельца.
