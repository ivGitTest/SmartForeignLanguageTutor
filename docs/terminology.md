# Терминология приложения

Используется во всех актуальных требованиях MVP и в дальнейшей документации. Условия согласованного веб-прототипа остаются историческими: общая терминология не меняет его функциональный объём.

| Термин | Значение |
|---|---|
| Режим Материалы | Аудиозапись, транскрибация, Перевод, список этих артефактов и работа с ними. |
| Режим Словарь | Словарь, карточки слов/выражений и их редактирование. Стартовый режим приложения. |
| Режим Обучение | Повторение слов/выражений и работа с карточками в учебной сессии. Запускается в том числе из режима Словарь. |
| А | Транскрибация, как есть: первоначально создаётся только из аудио; пользователь может затем редактировать её текст. |
| Б | Транскрибация с улучшением: создаётся только на основе сохранённой А с учётом целевого CEFR. Это не повторное распознавание аудио. |
| Перевод | Перевод Б на родной язык пользователя. По умолчанию свёрнут. |
| Контекстный перевод | Перевод выделенного слова/выражения с учётом предложения. Не подменяет артефакт Перевод. |
| Материал | Группа связанных артефактов: аудио, А, Б, Перевод; некоторые ещё могут отсутствовать. |
| Карточка | Английское слово/выражение, перевод, пример и данные повторения. Редактируется в режиме Словарь. |
| Учебная сессия | До 10 уникальных карточек с фиксированным составом; новые слова попадут только в следующую сессию. |
| Промпт | Видимая и редактируемая инструкция для соответствующей операции ИИ; её редактор по умолчанию свёрнут. |
| Резет настроек | Восстановление значений по умолчанию, включая промпты; не удаление материалов или прогресса. |

Режимы Материалы и Обучение независимы: для повторения не требуется сначала записывать аудио, а работа с материалами не требует учебной сессии. Приоритет режима Словарь означает старт со списка слов, а не ограничение остальных режимов.
