# Проверка реализации прототипа

Это отчёт о технической проверке, **не** окончательная приёмка качества ИИ.

Термины: [единый словарь](terminology.md). Отчёт относится к историческому веб-прототипу, не подтверждает реализацию или проверки мобильного MVP.

## Выполнено

| Проверка | Результат |
|---|---|
| Проверка типов всех пакетов проекта | Пройдена |
| Сборка сервера и веб-интерфейса | Пройдена |
| Серверные автоматические тесты | 5 пройдены |
| Запрос конфигурации и улучшения без сессии | HTTP 401, платный вызов не выполняется |
| Начало входа | Перенаправление на встроенный экран согласия |
| Запись → остановка → обновление страницы | Запись и проигрыватель восстановлены |
| Начало замены → отмена → обновление | Исходная запись сохранена |
| Изменение инструкции и параметров → сохранение → обновление | Значения восстановлены, редакция настроек сохранена |
| Удаление записи и результатов | Запись и тексты удалены, настройки сохранены |
| Запросы без подключённого ключа | Заблокированы, автоматических платных POST не было |
| Системная тёмная тема | Отображается |

Серверные тесты охватывают обе цели B2/C1, необязательный seed,
границы параметров и размеров текста/инструкции, запрет дополнительных
моделей/параметров, одну активную операцию и пять стартов за минуту,
проверку настоящего содержимого WAV/WebM/Ogg, повреждённое аудио и тишину.

## Ограничения этой проверки

- Браузерный проход выполнен в **Chrome 140**: Firefox не был доступен в
  автоматизированном окружении. Согласованная приёмка в Firefox ещё нужна.
- Закрытая рабочая область проверена с явно обозначенными браузерными
  тестовыми ответами для пользователя и конфигурации, не с реальной
  сессией владельца. База сервера и переменные окружения для теста не менялись.
- Вместо физического микрофона использован тестовый звуковой поток.
  Сохранение проверено, но проигрывание и слышимое качество не подтверждены.
- Завершение реального входа, доступ владельца и ответы OpenRouter пока
  не проверены: необходимы серверный ключ и ID владельца.
- Ответы распознавания и улучшения для этого прохода не подделывались.
  WER, дословность, сохранение смысла и качество B2/C1 **не оценены**.

контрольные записи и оба улучшения в Firefox по утверждённому ТЗ.
