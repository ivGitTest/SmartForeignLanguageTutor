# Описание целевого решения
Приложение для обучения иностранному языку. 
Основная идея: приложение позволяет учить язык подстраиваясь под словарный запас пользователя.
Идея: пользователь в настройках указывает текущий уровень языка и планируемый. Пользователь наговаривает текст, приложение выполняет две транскрибации:
* 1 к 1;
* с учетом планируемого уровня языка. Т.е.  усложняет, меняет слова на синонимы, усложняет грамматические констркции. 
Пользователь может добавить в словарь новые слова, учить их и позже научиться говорить и выражать те же мысли, но на более высоком уровне.
Приложение использует ИИ для работы с текстом.

## Пользовательские истории
### Настройки
1. Пользователь может настроить ключ/токен для подключения своих ИИ по API; MVP;
2. Пользователь может настроить ткущй уровень владения языком; MVP;
3. Пользователь может настроить плановый уровень владения языком; MVP;
4. Пользователь может настроить таймаут для внешних запросов;
	1. По умолчанию таймаут равен 10 секундам; MVP;
5. Пользователь может настроить язык приложения;
	1. По умолчанию выбран Английский язык; MVP;
6. Пользователь может выбрать язык обучения;
	1. В приложении доступен английский язык; MVP;
7. Пользователь может настроить тему оформления:
	* системная; MVP;
	* светлая;
	* тёмная;
8. Пользователь может настраивать количество слов за одну сессию в режиме обучения;
9. Приоложение определяет количество слов за одну сессию в режиме обучения по умолчанию = 10; MVP;
10. Пользователь может определить место хранения аудиозаписей в памяти телефона.
11. Приложение определяет место хранения аудиозаписей в памяти телефона по умолчанию в пользовательской области в каталоге <название приложения>. MVP;

### Общее
1. Пользователь должен видеть сообщение об ошбке если внешние сервисы недоступны; MVP;
2. Пользователь может включить запись микрофона и наговорить текст; MVP;
3. Пользователь может переключаться между режимами;  MVP;

### Работа с аудио
1. Пользователь может просматривать аудио записи в журнале аудиозаписей; MVP;
2. Пользователь может совершать действия над аудиозаписями:
	1. удалять; MVP;
	2. прослушивать; MVP;
	3. транскрибирвать как есть; MVP;
	4. транскрибировать с обработкой (усложнение до указанного в настройках планового уровня); MVP;
3. Приложение предоставляет место по умолчанию: каталог <название приложения> в пользовательстком пространстве телефона; MVP;
### Работа с текстом
1. Пользователь может совершать дейстия с текстовыми фрагментами:
	1. удалять; MVP;
	2. открывать текст; MVP;
	3. выделять слова/выражения в тексте для добавления в словарь (с переводом); MVP;
	4. Получать контекстный перевод слова; MVP;
	5. редактировать (стандартные функции с текстом); MVP;
	6. прослушивать; MVP;
2. Пользователь может выгрузить память устройства текстовые фрагменты;
### Работа со словарем
1. Пользователь может работать со словарём:
	1. Запускать обучение в режиме flash cards; MVP;
	2. Просматривать список слов; MVP;
	3. Редактировать карточку слова/перевод; MVP;
	4. Добавлять слова из текстового фрагмета с автоматическим перевдом; MVP;
	5. Добавлять слова и перевод напрямую в словарь; MVP;
2. Пользователь может выгрузить в память устройства список слов из словаря в формате anki;

# Технические требования
## Устройство
Прложение должно быть совместимо с мобильными телефонами на базе андроид 13и выше.
## Требования к Базе данных
SQLite

## Требования к Режиму рабты с текстом
1. Пользователь может выгрузить список текстовых фрагментов как csv. Поля:
	1. id;
	2. дата время записи;
	3. текстовый фрагмент - оригинал;
	4. текстовый фрагмент - обработанный;

## Требования к Алгоритму траскрибации с усложением
1. Приложение использует стандартные уровни владения языком CEFR. MVP;
2. Приложение должно дать задание ИИ так, что бы ИИ заменял слова на синонимы, использовал фразовые глаголы, грамматические правила соответствующие заданному уровню языка (плановый). MVP;

## Требования к Алгоритму работы в режиме обучения
1. Проводим анлогию с приложением Anki.
2. Приложение представляет два режима работы для обучения:
	1. FSRS:
		1. Используй готовые библиотеки (https://github.com/open-spaced-repetition/awesome-fsrs);
	2. Классически алгоритм SM-2 (SuperMemo-2).  MVP;
3. Формат экспорта словаря: какв anki;
